# TaskFlow — Collaborative Task & Project Management Platform

A full-stack, real-time project management application (like a mini Trello/Asana) built with **React**, **FastAPI**, **REST APIs**, and **MongoDB**. Teams can create projects, organize work on kanban boards, assign tasks, comment, and see updates from teammates instantly via WebSockets.

## ✨ Features

- 🔐 **Authentication** — JWT-based signup/login with hashed passwords (bcrypt)
- 📁 **Projects** — create projects, invite/remove members by email
- 🗂️ **Kanban board** — drag-and-drop tasks across To Do / In Progress / Done
- ✅ **Tasks** — title, description, priority, assignee, due date
- 💬 **Comments** — threaded comments on each task
- ⚡ **Real-time sync** — WebSocket broadcasts so every collaborator's board updates live, with no refresh
- 📊 **Analytics** — task distribution chart and overdue-task count per project
- 🐳 **Dockerized** — one command to spin up MongoDB, the API, and the frontend together

## 🧱 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18, React Router, Axios, Recharts |
| Backend | FastAPI, Motor (async MongoDB driver), Pydantic v2 |
| Database | MongoDB |
| Auth | JWT (python-jose) + bcrypt (passlib) |
| Real-time | Native WebSockets (FastAPI) |
| Deployment | Docker + docker-compose, Nginx (frontend) |

## 🚀 Getting Started

### Option A — Run with Docker (recommended, fastest)

Requires only Docker and Docker Compose installed.

```bash
git clone <your-repo-url>
cd task-manager
docker compose up --build
```

- Frontend: http://localhost:3000
- Backend API docs (Swagger): http://localhost:8000/docs
- MongoDB: localhost:27017

That's it — MongoDB, the FastAPI backend, and the React frontend all start together.

### Option B — Run manually (for local development)

**1. MongoDB**
Run MongoDB locally, or via Docker:
```bash
docker run -d -p 27017:27017 --name mongo mongo:7
```

**2. Backend**
```bash
cd backend
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env       # edit if needed
uvicorn app.main:app --reload
```
API runs at `http://localhost:8000` — interactive docs at `/docs`.

**3. Frontend**
```bash
cd frontend
npm install
npm start
```
App runs at `http://localhost:3000`.

## 🔑 Environment Variables (backend/.env)

| Variable | Description | Default |
|---|---|---|
| `MONGO_URI` | MongoDB connection string | `mongodb://localhost:27017` |
| `DATABASE_NAME` | Database name | `task_manager` |
| `JWT_SECRET_KEY` | Secret used to sign JWTs — **change in production** | — |
| `JWT_ALGORITHM` | JWT signing algorithm | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Token lifetime | `1440` (24h) |
| `CORS_ORIGINS` | Comma-separated allowed origins | `http://localhost:3000` |

## 📡 API Overview

All endpoints are prefixed as shown; full interactive docs are auto-generated by FastAPI at `/docs`.

| Method | Endpoint | Description |
|---|---|---|
| POST | `/auth/register` | Create an account |
| POST | `/auth/login` | Log in, returns JWT |
| GET | `/auth/me` | Get current user |
| GET | `/users/search?q=` | Search users by name/email |
| GET/POST | `/projects` | List / create projects |
| GET/PATCH/DELETE | `/projects/{id}` | Get / update / delete a project |
| POST | `/projects/{id}/members` | Add a member by email |
| DELETE | `/projects/{id}/members/{member_id}` | Remove a member |
| GET/POST | `/projects/{id}/tasks` | List / create tasks |
| PATCH/DELETE | `/projects/{id}/tasks/{task_id}` | Update / delete a task |
| POST | `/projects/{id}/tasks/{task_id}/comments` | Add a comment |
| WS | `/ws/projects/{id}?token=` | Real-time board updates |

## 🗺️ Architecture Notes

- **Async all the way down**: FastAPI + Motor means the API never blocks on I/O, so it scales well under concurrent load.
- **Access control**: every project/task route checks that the requesting user is either the project owner or a member before returning data.
- **Real-time without polling**: task create/update/delete events are broadcast over a WebSocket per project room, so collaborators see changes instantly instead of the frontend polling the API.
- **Optimistic UI**: dragging a task between columns updates the UI immediately and reverts only if the API call fails.
